# Runbooks

Store reproducible commands here only after removing API keys, passwords, local
tokens, and private server addresses. Command notes that still contain
credentials belong under ignored `secrets/`.

- `glm47_tagged_api_generation.md`: GLM-4.7 tagged CoT API smoke runs,
  raw request/response audit fields, and output-directory rules.
- `cds_glm47_qwen3_embedding_0p6b_batch256.md`: 5090-host Qwen3
  Embedding 0.6B CDs_and_Vinyl training and evaluation run, with the required
  print-only parameter confirmation gate before training.
